เปรียบเทียบ D3.js กับ ECharts

ข้อมูลชุดเดียวกัน กราฟชุดเดียวกัน ต่างกันเฉพาะเครื่องมือ

เครื่องมือข้อดีข้อเสีย
D3.js v7 หน้านี้
  • ควบคุมได้ทุกองค์ประกอบ ออกแบบกราฟรูปแบบใหม่ได้ไม่จำกัด
  • ไลบรารีเล็ก (~93 KB gzip) และวาดเร็ว
  • ปรับรายละเอียดได้ละเอียด เช่น แท่งมนเฉพาะปลาย ช่องว่าง 2px ระหว่างส่วนซ้อน
  • มีเครื่องมือเฉพาะทาง เช่น projection แผนที่ และ Delaunay หาจุดที่ใกล้เมาส์ที่สุด
  • ต้องเขียนเองทุกอย่าง ทั้งแกน tooltip legend แอนิเมชัน และการย่อขยายตามจอ
  • โค้ดยาวกว่ามาก (427 บรรทัด เทียบกับ 268) ใช้เวลาพัฒนานานกว่า
  • เรียนรู้ยาก ต้องเข้าใจ scale, selection และ data join
  • แผนที่ต้องเตรียมข้อมูลเอง เช่น เรียงทิศทางจุดของ polygon ให้ถูก
Apache ECharts 5
  • กำหนดกราฟด้วย option object เขียนสั้นและเร็ว
  • มี tooltip, legend, visualMap และไฮไลต์เมื่อชี้มาให้ในตัว แอนิเมชันเปลี่ยนสถานะได้ด้วยการตั้งค่าเพียงไม่กี่บรรทัด
  • แผนที่ใช้ได้ทันทีด้วย registerMap + series แบบ map
  • เรียนรู้ง่าย เอกสารและตัวอย่างเยอะ
  • ไลบรารีใหญ่ (~334 KB gzip)
  • วาดใหม่ช้ากว่าเมื่อเปลี่ยนตัวกรอง
  • ปรับได้เท่าที่ option รองรับ งานนอกกรอบทำได้ยาก
  • บางอย่างต้องคำนวณเอง เช่น ตำแหน่ง grid ของ small multiples เป็นพิกเซล
ประเด็นD3.js v7 หน้านี้ECharts 5
